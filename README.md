# StreamStats — Support

StreamStats is a Safari extension for macOS that displays the current Netflix video playback resolution.

## How to Use

1. Install StreamStats from the Mac App Store.
2. Open Safari → Settings → Extensions.
3. Enable StreamStats.
4. Open Netflix and start playing a video.
5. Click the StreamStats icon in Safari's toolbar to view the current playback resolution.

## Troubleshooting

**No resolution displayed?**

- Make sure a Netflix video is playing.
- Confirm StreamStats is enabled in Safari's extension settings.
- Allow StreamStats access to netflix.com if Safari requests permission.
- Refresh the Netflix page and try again.

**Resolution lower than expected?**

StreamStats reports the video dimensions provided by Safari. It does not control or improve streaming quality.
